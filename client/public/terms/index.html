Termos de Serviço

Condições para uso do ClipPublisher e das integrações com plataformas de terceiros.

Última atualização: 22 de setembro de 2026

1. Sobre o serviço

O ClipPublisher é uma aplicação web para preparar vídeos MP4 e MOV e enviá-los ao TikTok para publicação por meio da API oficial disponibilizada pela plataforma.

2. Uso do serviço

O usuário é responsável pelos vídeos, textos, hashtags e demais conteúdos enviados pelo serviço e deve possuir os direitos e autorizações necessários para publicá-los.

O usuário também é responsável por respeitar os termos, políticas e limites do TikTok. O ClipPublisher não é afiliado, patrocinado ou endossado pelo TikTok.

3. Conexões com plataformas

Quando o usuário conecta uma conta, o ClipPublisher utiliza a autorização concedida para executar as operações solicitadas. As permissões solicitadas são limitadas às funcionalidades necessárias para a integração configurada.

4. Disponibilidade

O serviço é fornecido conforme disponibilidade. Integrações de terceiros podem sofrer alterações, limitações, indisponibilidades ou mudanças de políticas fora do controle do ClipPublisher.

5. Conteúdo e responsabilidade

O usuário permanece responsável pelo conteúdo publicado e pelas consequências de sua publicação. O ClipPublisher não reivindica propriedade sobre os vídeos enviados pelo usuário.

6. Alterações

Estes termos podem ser atualizados para refletir alterações no serviço, nas integrações ou em requisitos legais. A versão vigente será disponibilizada nesta página.

7. Contato

O repositório do ClipPublisher não informa um endereço ou formulário de contato. Para questões sobre estes termos, procure o operador do serviço pelo canal que ele fornecer diretamente.
