Política de Privacidade

Como os dados são tratados ao preparar e publicar vídeos pelo ClipPublisher.

Última atualização: 22 de setembro de 2026

1. Dados tratados

O ClipPublisher trata dados necessários para autenticar e operar as integrações autorizadas pelo usuário, incluindo identificadores da conta conectada, tokens de acesso e informações retornadas pelas APIs das plataformas. Vídeos e metadados fornecidos pelo usuário são processados para executar a publicação solicitada.

2. Tokens de acesso

Os tokens de integração são armazenados no servidor em arquivo criptografado com AES-256-GCM. Eles não são enviados ao navegador, e os campos de token são ocultados dos logs da aplicação.

3. Arquivos enviados

Os vídeos são armazenados temporariamente no servidor durante o processamento. O sistema remove arquivos temporários com idade superior ao período configurado no servidor (24 horas por padrão). Um vídeo pode permanecer disponível enquanto o TikTok conclui o processamento ou para permitir nova tentativa após uma falha, sujeito à limpeza periódica.

4. Compartilhamento

O ClipPublisher envia dados e conteúdo às plataformas conectadas somente quando necessário para executar a ação solicitada, como autorizar uma conta ou publicar um vídeo. Não vendemos dados pessoais.

5. Serviço de terceiros

A integração de publicação com o TikTok está sujeita às políticas de privacidade, termos de serviço e práticas de tratamento de dados dessa plataforma.

6. Segurança

São adotadas medidas técnicas para proteger credenciais e arquivos processados. Nenhum método de transmissão ou armazenamento eletrônico é absolutamente seguro, portanto não é possível garantir segurança absoluta.

7. Solicitações sobre dados

O repositório do ClipPublisher não informa um endereço ou formulário de contato para solicitações sobre dados. As solicitações devem ser encaminhadas ao operador do serviço pelo canal que ele fornecer diretamente.

8. Alterações

Esta política poderá ser atualizada para refletir mudanças no serviço, nas integrações ou na legislação aplicável. A data da última atualização será indicada no início desta página.
